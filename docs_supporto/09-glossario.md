# Glossario

| Termine | Cosa vuol dire |
| --- | --- |
| Azoto al campo | L'azoto che arriva al campo, al netto di quello perso in stalla e in vasca |
| Azoto utile o efficiente | La parte dell'azoto sparso che la coltura usa davvero |
| BDN | Banca dati nazionale dell'anagrafe zootecnica: capi e allevamenti |
| Carrobotte | Rimorchio cisterna trainato da un trattore, per trasportare e spandere liquame |
| Cessione, contratto di cessione | L'accordo con cui un'azienda cede effluenti a un'altra che li usa sui suoi terreni |
| Comunicazione | La dichiarazione obbligatoria su quanto refluo si produce, dove si sparge e a chi si cede |
| Contoterzista | Impresa che fa lavori agricoli per conto di altri |
| Contributo | Ciò che paga chi cede per far arrivare il refluo oltre il raggio di convenienza |
| Detentore | Chi riceve gli effluenti con un contratto e ne risponde per le fasi che gestisce |
| DGR 585/2020 | La disciplina della Regione Campania sull'uso agronomico di effluenti e digestato |
| Digestato | Ciò che esce da un impianto di biogas dopo la digestione |
| Divieto invernale | Il periodo in cui non si può spandere perché le colture non assorbono |
| DLG | Ente tedesco che prova e certifica macchine e sensori agricoli |
| DM 5046/2016 | Il decreto nazionale con le regole tecniche per l'uso agronomico degli effluenti |
| Documento di trasporto | Il documento che accompagna ogni trasporto di effluenti |
| Effluenti, reflui | Le deiezioni degli animali, con lettiera e acque di lavaggio |
| Filtro di Kalman | Metodo che combina una previsione con misure imprecise; qui stima il livello della vasca |
| Frazione solida e chiarificata | Le due parti in cui un separatore divide il refluo |
| Giorni utili | Giorni in cui spandere è permesso e possibile |
| Hub di trattamento | Impianto dove il refluo viene separato, digerito, concentrato o privato dell'azoto |
| Interramento | Incorporare il refluo nel terreno subito dopo averlo sparso, per perdere meno ammoniaca |
| Letame | Effluente solido, con paglia |
| Liquame | Effluente liquido: feci, urine e acque di lavaggio |
| LoRaWAN | Rete radio a basso consumo per sensori, con portata di chilometri |
| NIR | Spettroscopia nel vicino infrarosso: il sensore illumina il refluo e dalla luce riflessa stima cosa contiene |
| Ottimizzazione a costo minimo | Metodo matematico che trova il piano più economico rispettando i vincoli |
| PLS | Metodo statistico che collega le letture NIR alle analisi di laboratorio |
| PUA | Piano di utilizzazione agronomica: su quali terreni, quando e quanto refluo spandere |
| Raggio di convenienza | La distanza entro cui trasportare il refluo costa meno dell'urea che sostituisce |
| RefluiZoo | La piattaforma della Regione Campania per inviare la Comunicazione |
| Registro delle utilizzazioni | Il registro in cui chi sparge annota date, campi e quantità |
| RENURE | Azoto recuperato dagli effluenti in forma simile a un concime minerale; potrà superare i 170 kg |
| RiduciN | Progetto campano che riduce l'azoto dei reflui con l'elettro-ossidazione |
| SRG01 | Intervento del CSR Campania 2023–2027 che finanzia gruppi operativi per l'innovazione |
| STP | Servizio territoriale provinciale della Regione, l'ufficio che riceve le Comunicazioni |
| Tal quale | Refluo così com'è, non trattato |
| UBA | Unità di bestiame adulto: serve a sommare animali diversi |
| Urea | Concime azotato di sintesi con il 46% di azoto; il riferimento per il prezzo dell'azoto |
| Zona vulnerabile ai nitrati (ZVN) | Area con acque inquinate o a rischio per i nitrati: limite di 170 kg di azoto per ettaro |
| Zona ordinaria (ZO) | Area non vulnerabile: limite di 340 kg di azoto per ettaro |
